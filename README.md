# Eliph — Elliot Phua Personal Portfolio Workspace (`eliph`)

A minimalist, highly optimized engineering portfolio built to showcase technical architecture, systems design principles, and personal software engineering projects. 

The application architecture prioritizes speed, strict type safety, and clean layout scaling, combining utility styling paradigms with responsive material interface nodes.

---

## 🛠️ Tech Stack & Architecture

* **Core Framework:** React 19 (Functional Components, Hooks API)
* **Build Pipeline & HMR:** Vite 8 (Ultra-fast module bundling)
* **Programming Language:** TypeScript 6 (Strict compiler configurations)
* **Styling Engine:** Mixed Paradigms
    * **Tailwind CSS v4:** Handles layout mechanics, fluid breakpoints, and low-level structural utility scaffolding.
    * **Material UI (MUI) v6:** Drives interface surface rendering, consistent layout baselines, and modular component typography blocks.
* **Deployment Pipeline:** GitHub Actions CI/CD (Node 24 runner compiling down to GitHub Pages layout targets)

---
